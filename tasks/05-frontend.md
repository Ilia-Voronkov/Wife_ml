# Задача 5: Фронтенд (веб-страница)

## Цель
Создать простую веб-страницу, где можно вставить текст резюме и вакансии, нажать кнопку и увидеть результат анализа.

## Что нужно узнать

**Фронтенд** — это то, что видит пользователь в браузере. Он состоит из трёх частей:
- **HTML** — структура страницы (что показывать)
- **CSS** — стили (как это выглядит)
- **JavaScript** — логика (что происходит при нажатии кнопки)

Наш фронтенд будет отправлять данные на наш API и показывать результат.

## Что нужно сделать

### 1. Создать `frontend/index.html`:
- Заголовок страницы: "AI CV Match Analyzer"
- Два текстовых поля (`<textarea>`):
  - Для текста резюме (id="cv-text", placeholder="Вставьте текст резюме...")
  - Для текста вакансии (id="job-text", placeholder="Вставьте описание вакансии...")
- Кнопка "Анализировать" (id="analyze-btn")
- Блок для результата (id="result", изначально скрыт)
- Подключить `style.css` и `script.js`

### 2. Создать `frontend/style.css`:
- Простой, чистый дизайн
- Центрировать содержимое
- Стилизовать текстовые поля (ширина, высота, рамка)
- Стилизовать кнопку (цвет, размер)
- Стилизовать блок результата

### 3. Создать `frontend/script.js`:
- При нажатии кнопки:
  1. Взять текст из обоих полей
  2. Отправить POST-запрос на `http://localhost:8000/analyze`
  3. Показать результат в блоке result:
     - Score (с цветом: зелёный > 70, жёлтый > 40, красный <= 40)
     - Список matching skills
     - Список missing skills
     - Список suggestions

### 4. Обновить `app/api.py`:
Добавить поддержку статических файлов и CORS:
```python
from fastapi.staticfiles import StaticFiles
from fastapi.middleware.cors import CORSMiddleware
```

## Как проверить

1. Запусти сервер: `python main.py`
2. Открой http://localhost:8000/frontend/index.html
3. Вставь текст резюме и вакансии
4. Нажми "Анализировать"
5. Результат должен отобразиться на странице

## Подсказки

- `fetch()` — функция JavaScript для отправки HTTP-запросов
- `document.getElementById()` — получить элемент по id
- `JSON.stringify()` — превратить объект в JSON-строку
- `element.innerHTML` — установить HTML-содержимое элемента
- Для CORS добавь middleware, который разрешает все origins (для разработки)
